# jpeg-decoder

JPEG Decoder — проект на **C++**, посвящённый реализации и изучению основных этапов декодирования JPEG-изображений.

Проект охватывает низкоуровневую обработку бинарного JPEG-потока, Huffman-декодирование, обратное дискретное косинусное преобразование, восстановление изображения, а также работу с baseline и progressive JPEG.

Основной акцент сделан на понимании внутреннего устройства JPEG, работе с алгоритмами сжатия и обработке бинарных данных на C++.

## Основные возможности

* разбор структуры JPEG-файла;
* обработка бинарного потока данных;
* Huffman-декодирование;
* работа с DCT-коэффициентами;
* деквантизация коэффициентов;
* выполнение обратного дискретного косинусного преобразования — IDCT;
* восстановление блоков изображения;
* работа с baseline JPEG;
* работа с progressive JPEG;
* преобразование декодированных данных в RGB-изображение;
* сравнение результата с эталонным декодером на базе `libjpeg`;
* fuzz-тестирование компонентов декодера.

## Архитектура декодирования

Упрощённый pipeline декодирования JPEG:

```text
JPEG byte stream
        │
        ▼
Разбор JPEG-маркеров
        │
        ▼
Чтение таблиц квантования
        │
        ▼
Чтение Huffman-таблиц
        │
        ▼
Entropy decoding
        │
        ▼
Восстановление DCT-коэффициентов
        │
        ▼
Dequantization
        │
        ▼
IDCT
        │
        ▼
Восстановление компонентов изображения
        │
        ▼
Преобразование цветового пространства
        │
        ▼
RGB Image
```

Разделение проекта на независимые компоненты позволяет отдельно работать с алгоритмами энтропийного декодирования, преобразованиями изображения и различными режимами JPEG.

## Huffman Decoding

JPEG использует Huffman coding на этапе энтропийного кодирования данных.

Для работы с Huffman-кодами в проекте используется отдельный компонент:

```cpp
class HuffmanTree {
public:
    void Build(
        const std::vector<uint8_t>& code_lengths,
        const std::vector<uint8_t>& values
    );

    bool Move(bool bit, int& value);
};
```

Таблица кодов строится на основе длин кодовых слов и соответствующих им значений.

После этого входной битовый поток последовательно обрабатывается для восстановления закодированных JPEG-коэффициентов.

## DCT / IDCT

JPEG хранит изображение не напрямую в виде RGB-пикселей, а использует представление в частотной области.

Каждый блок изображения преобразуется с помощью **Discrete Cosine Transform** и после декодирования должен быть восстановлен обратным преобразованием:

```text
DCT coefficients
       │
       ▼
Dequantization
       │
       ▼
Inverse DCT
       │
       ▼
Pixel values
```

Для выполнения обратного преобразования проект использует библиотеку **FFTW**.

Основной интерфейс:

```cpp
class DctCalculator {
public:
    DctCalculator(
        size_t width,
        std::vector<double>* input,
        std::vector<double>* output
    );

    void Inverse();
};
```

## Baseline JPEG

Baseline JPEG использует последовательное кодирование коэффициентов изображения.

Основной интерфейс декодера:

```cpp
Image Decode(std::istream& input);
```

Декодер получает бинарный JPEG-поток и формирует объект изображения с RGB-пикселями.

Типичный процесс включает:

```text
JPEG stream
    ↓
Headers
    ↓
Quantization tables
    ↓
Huffman tables
    ↓
MCU decoding
    ↓
Dequantization
    ↓
IDCT
    ↓
Color conversion
    ↓
Image
```

## Progressive JPEG

Progressive JPEG отличается от baseline-варианта тем, что информация об изображении передаётся несколькими scan'ами.

Вместо передачи всех коэффициентов сразу изображение постепенно уточняется:

```text
Scan 1
  ↓
Базовая информация

Scan 2
  ↓
Дополнительные коэффициенты

Scan 3
  ↓
Уточнение изображения

...
```

Работа с progressive JPEG требует сохранения промежуточного состояния коэффициентов между отдельными scan'ами и их последующего объединения.

## Faster Decoder

В проекте также выделена отдельная реализация декодера, ориентированная на исследование производительности.

Такое разделение позволяет:

* сохранять простую базовую реализацию;
* отдельно экспериментировать с оптимизациями;
* сравнивать разные подходы к обработке JPEG;
* уменьшать количество лишних операций и аллокаций;
* анализировать влияние структуры алгоритма на производительность.

## Работа с изображением

Для хранения результата используется собственное представление RGB-изображения.

Вспомогательные компоненты позволяют:

* работать с отдельными пикселями;
* хранить размеры изображения;
* сравнивать изображения;
* сохранять результат в PNG;
* получать эталонное декодирование через `libjpeg`.

Это позволяет проверять собственный decoder относительно широко используемой JPEG-библиотеки.
